# Sanchala OS Notification Sounds

This directory contains notification sounds for Sanchala OS.

## Sound Files

| File | Purpose | Duration |
|------|---------|----------|
| default.ogg | Standard notifications | ~0.5s |
| critical.ogg | Critical alerts | ~1.0s |
| message.ogg | Messages/Chat | ~0.3s |
| reminder.ogg | Calendar/Reminders | ~0.7s |
| system.ogg | System events | ~0.4s |
| ringtone.ogg | Incoming calls | ~3.0s |
| sent.ogg | Message sent | ~0.2s |

## Design Guidelines

- Clean, subtle tones (inspired by macOS/iOS)
- Non-intrusive but noticeable
- Consistent audio levels
- OGG Vorbis format for quality/size balance
