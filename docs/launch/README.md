## Key Messages

### Primary Message
> SANCHALA OS: Set your system in motion with security beyond Apple and the beauty of macOS — powered by Linux.

### Supporting Messages

1. **Security First**
   > 8-layer security architecture that goes beyond macOS, with full transparency and open source code.

2. **Beautiful Design**
   > macOS-inspired experience on Linux: floating dock, global menu, blur effects, and 60fps animations.

3. **100% Compatible**
   > All your Linux apps work. Flatpak, Pacman, AUR, and AppImage — no compromise.

4. **Reliable & Recoverable**
   > Btrfs snapshots before every update. One click to roll back. Never lose your system.
