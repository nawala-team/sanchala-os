# Per-Application Shortcuts

Application-specific keyboard shortcuts for Sanchala OS default applications.

## Dolphin (File Manager)

### Navigation
| Shortcut | Action |
|----------|--------|
| `Alt+Left` | Go Back |
| `Alt+Right` | Go Forward |
| `Alt+Up` | Go Up |
| `Alt+Home` | Go Home |
| `Ctrl+L` | Location Bar |

### View
| Shortcut | Action |
|----------|--------|
| `F3` | Split View |
| `F4` | Terminal Panel |
| `Ctrl+1` | Icon View |
| `Ctrl+2` | Compact View |
| `Ctrl+3` | Details View |
| `Ctrl+H` | Show Hidden Files |
| `Ctrl++/-` | Zoom In/Out |

### File Operations
| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+N` | New Folder |
| `Ctrl+T` | New Tab |
| `Ctrl+W` | Close Tab |
| `F2` | Rename |
| `Ctrl+Del` | Move to Trash |
| `Alt+Return` | Properties |
| `Ctrl+C/X/V` | Copy/Cut/Paste |
| `Ctrl+F` | Find |

| `Ctrl+PgUp/PgDown` | Previous/Next Tab |

### Edit
| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+C` | Copy |
| `Ctrl+Shift+V` | Paste |
| `Ctrl+Shift+F` | Find |

### View
| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+L` | Split Left/Right |
| `Ctrl+Shift+H` | Split Top/Bottom |
| `F11` | Fullscreen |
