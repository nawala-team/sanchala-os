# 📊 Feedback Collection System

> Structured feedback channels for Sanchala OS Beta Program

---

## Overview

We use multiple feedback channels to gather diverse input from beta testers. Each channel serves a specific purpose and type of feedback.

---

## Feedback Channels

| Channel | Purpose | Best For |
|---------|---------|----------|
| GitHub Issues | Bug tracking | Reproducible bugs, feature requests |
| GitHub Discussions | Community Q&A | Questions, ideas, brainstorming |
| In-App Feedback | Quick contextual | UI observations, quick reactions |
| Surveys | Quantitative data | Satisfaction, prioritization |
| Beta Forum | Discussion | Experience sharing, peer support |

---

## Survey Schedule

| Survey | When | Duration | Focus |
|--------|------|----------|-------|
| Onboarding | After first week | 5 min | Initial impressions |
| Mid-Beta | Week 3 | 10 min | Feature feedback |
| Exit Survey | End of phase | 15 min | Overall experience |

---

## Onboarding Survey

1. Rate the installation process (1-5)
2. Did you encounter installation issues? (Y/N + details)
3. How long did installation take?
4. First impression of Sanchala OS? (1-5)
5. What's the first thing you noticed?
6. What OS were you using before?
7. Linux experience level?
8. Primary use case?

---

## Mid-Beta Survey

1. How often have you used Sanchala OS this week?
2. Is it your primary OS?
3. Rate these features (1-5): Desktop, Security, Performance, Tools
4. Which feature needs most improvement?
5. What feature is missing?
6. What frustrates you most?
7. Have you encountered bugs?

---

## Exit Survey

1. Overall satisfaction (1-10)
2. How likely to recommend? (NPS 0-10)
3. Rate: Stability, Performance, Security, Design, Ease of use
4. Will you continue using Sanchala OS?
5. Best thing about Sanchala OS?
6. Worst thing about Sanchala OS?
7. Any other feedback?

---

## In-App Feedback Tool

Access via: System tray → Sanchala Feedback (or `sanchala-feedback`)

**Quick Rating:** 😟 😐 🙂 😊 🤩

**Categories:**
- Performance issue
- Visual/UI issue  
- Feature suggestion
- Something broken
- General feedback

**Options:**
- Include screenshot
- Include system info

---

## Telemetry (Opt-in Only)

### Collected (with consent)
- Installation success/failure
- Hardware config (anonymized)
- Feature usage frequency
- Crash reports

### NOT Collected
- File contents, browsing history, passwords, location

**Settings:** Sanchala Settings → Privacy → Telemetry

---

## Feedback Processing

| Feedback Type | Response Time |
|---------------|---------------|
| Bug report | 24-72 hours |
| Security issue | 4 hours |
| Feature request | Weekly triage |
| General feedback | Batch acknowledged |
