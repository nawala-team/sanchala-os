# 🔍 Sanchala Search - Quick Reference Card

## Activation
| Shortcut | Action |
|----------|--------|
| `Meta+Space` | Open Search |
| `Escape` | Close |
| `Enter` | Execute |
| `Ctrl+Enter` | Secondary action |

---

## Search Types

### Applications
```
firefox          → Launch Firefox
term             → Open Terminal
settings         → System Settings
```

### Files & Folders
```
report.pdf       → Find by name
~/Documents      → Open folder
*.jpg            → Find by extension
```

### Content Search
```
content:invoice  → Search inside documents
"exact phrase"   → Exact match
budget 2024      → Full-text search
```

---

## Calculator (`=`)
```
=2+2             → 4
=sqrt(144)       → 12
=15% of 200      → 30
=sin(45 deg)     → 0.707
=0xFF            → 255
=toHex(255)      → 0xFF
```

**Functions**: sin, cos, tan, sqrt, log, ln, exp, abs, ceil, floor, round, factorial

**Constants**: pi, e, phi

---

## Unit Conversion
```
5 km in miles    → 3.107 mi
100 F to C       → 37.78 °C
1 GB in MB       → 1024 MB
2 hours in min   → 120 min
```

**Categories**: length, weight, temperature, volume, speed, data, time, area, pressure

- Recent items appear first
- `Tab` cycles through categories
- `Ctrl+C` copies calculator results
