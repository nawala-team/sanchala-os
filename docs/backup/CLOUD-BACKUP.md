# ☁️ Sanchala OS - Cloud Backup Guide

## Overview

Sanchala OS integrates with rclone to provide cloud backup to 40+ storage providers including Google Drive, OneDrive, Dropbox, and S3-compatible services.

---

## 🚀 Quick Setup

### 1. Configure Cloud Storage
```bash
# Interactive setup wizard
sudo sanchala-backup cloud setup

# Or specify provider directly
sudo sanchala-backup cloud setup gdrive
```

### 2. Test Connection
```bash
sanchala-backup cloud status
```

### 3. Run First Sync
```bash
sudo sanchala-backup cloud sync
```

## ⚙️ Configuration

### Config File: `/etc/sanchala/backup.toml`

```toml
[cloud]
enabled = true
remote = "gdrive"
schedule = "daily"
time = "03:00"

# Directories to sync
sync_paths = ["/home"]
```

### Rclone Config: `/etc/sanchala/rclone.conf`

Generated by `cloud setup`. Contains encrypted credentials.

---

## 📂 What Gets Backed Up

### Default Sync Paths
- `/home` - All user data

### Excluded by Default
- `.cache/` - Cache directories
- `.local/share/Trash/` - Trash
- `Downloads/` - Downloads folder
- `*.tmp`, `*.log` - Temporary files

### Customize Exclusions
Edit `/etc/sanchala/backup.toml`:
```toml
[exclude]
paths = [
    "/home/*/.cache",
    "/home/*/Downloads",
    "*.tmp",
]
```

## 🔄 Sync Modes

### Manual Sync
```bash
sudo sanchala-backup cloud sync
```

### Scheduled Sync
```bash
# Enable daily sync at 3 AM
sudo systemctl enable --now sanchala-cloud-sync.timer
```

### Dry Run (Preview)
```bash
rclone sync /home remote:backup --dry-run
```

## 🔐 Security

### Encryption
For end-to-end encryption, use rclone crypt:
```bash
rclone config
# Create new remote → choose "crypt"
# Set underlying remote to your cloud storage
```

### Two-Factor Auth
Most providers support 2FA. Configure through provider's web interface.

## 📊 Monitor & Verify

### Check Status
```bash
sanchala-backup cloud status
```

### List Remote Files
```bash
rclone ls remote:sanchala-backup/
```

### Verify Backup Integrity
```bash
rclone check /home remote:sanchala-backup/home
```

---

## 🔄 Restore from Cloud

### Restore to Original Location
```bash
# Preview first
rclone sync remote:sanchala-backup/home /home --dry-run

# Actual restore
sudo rclone sync remote:sanchala-backup/home /home
```

### Restore to Different Location
```bash
rclone copy remote:sanchala-backup/home /mnt/restore/
```

### Restore Single File
```bash
rclone copy remote:sanchala-backup/home/user/documents/file.txt ./
```

## 🛠️ Troubleshooting

### Authentication Failed
```bash
# Re-authenticate
rclone config reconnect remote:
```

### Slow Upload
```bash
# Increase transfers
rclone sync /home remote:backup --transfers 8
```

### Quota Exceeded
```bash
# Check usage
rclone about remote:
```
