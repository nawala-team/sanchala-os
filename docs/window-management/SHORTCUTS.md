# SANCHALA OS - Complete Keyboard Shortcuts

## Window Management

### Basic Operations
| Shortcut | Action |
|----------|--------|
| `Meta+Q` | Close window |
| `Meta+H` | Minimize (hide) |
| `Meta+F` | Maximize/restore |
| `Meta+Shift+F` | Fullscreen |
| `Alt+F4` | Force close |
| `Alt+F3` | Window menu |

### Window Switching
| Shortcut | Action |
|----------|--------|
| `Alt+Tab` | Cycle windows |
| `Alt+Shift+Tab` | Cycle reverse |
| `Alt+`` ` | Current app windows |
| `Meta+W` | Overview |

### Window Movement
| Shortcut | Action |
|----------|--------|
| `Meta+Shift+Left` | To left screen |
| `Meta+Shift+Right` | To right screen |
| `Meta+Shift+C` | Center window |
| `Meta+Shift+A` | Always on top |
| `Meta+Shift+D` | All desktops |
