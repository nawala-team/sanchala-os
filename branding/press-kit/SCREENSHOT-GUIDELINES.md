## Technical Specifications

### Resolution
- **Primary:** 3840x2160 (4K)
- **Fallback:** 1920x1080 (HD)
- **Aspect Ratio:** 16:9

### Format
- **PNG** for lossless quality
- **WebP** for web (80% quality)
- **JPG** for social (90% quality)

### Naming Convention
```
sanchala-{feature}-{variant}-{resolution}.{ext}

Examples:
sanchala-desktop-dark-4k.png
sanchala-guardian-light-hd.webp
sanchala-appstore-dark-4k.jpg
```

---

## Visual Standards

### Wallpaper
- Use official Gati wallpapers only
- Match wallpaper to theme (dark/light)

### Window Placement
- Center primary window or use rule of thirds
- 2-3 windows maximum for busy shots
- Avoid window overlap covering key content

### Content Guidelines
- Use placeholder data (no real personal info)
- Show realistic but curated file names
- Display professional app selection

### Prohibited Content
- ❌ Personal files or real usernames
- ❌ Third-party branding prominently visible
- ❌ Cluttered or messy desktops
- ❌ Error dialogs or broken states
- ❌ Outdated or placeholder UI

## Post-Processing

### Allowed
- Crop to standard aspect ratios
- Color correction to match brand
- Add drop shadow for floating effect

### Not Allowed
- Alter UI elements
- Add fake features
- Modify brand colors in UI
