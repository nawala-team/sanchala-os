## Boilerplate (Short)

> SANCHALA OS is a beautiful, secure Linux distribution that combines macOS-inspired design with security beyond Apple. Built on Arch Linux with KDE Plasma 6, it delivers 8-layer security architecture, seamless package management, and a premium user experience.

## Boilerplate (Long)

> SANCHALA OS reimagines what a Linux desktop can be. Drawing inspiration from the Sanskrit word "Sanchala" meaning "to set in motion," it combines the elegance of macOS with the power and security of Linux.
>
> Built on the rock-solid Arch Linux foundation with KDE Plasma 6, SANCHALA OS features an 8-layer security architecture that goes beyond Apple's approach — including mandatory sandboxing, post-quantum cryptography readiness, and a transparent permission system. The result is an operating system that's both beautiful and trustworthy.
>
> With support for Flatpak, Pacman, AUR, and AppImage, users have access to thousands of applications while maintaining security through automatic sandboxing. Btrfs snapshots ensure easy recovery, and delta updates keep the system efficient.

## Key Features

### 🎨 Design
- macOS-inspired UI with floating dock
- Global menu bar and traffic light buttons
- Blur effects and 60fps animations
- Dark/Light themes with auto-switch

### 🔒 Security
- 8-layer security architecture
- Mandatory AppArmor sandboxing
- TPM 2.0 & Secure Boot support
- Full disk encryption (LUKS2)
- Post-quantum cryptography ready

### 📦 Compatibility
- Flatpak (primary, sandboxed)
- Pacman (system packages)
- AUR (community)
- AppImage (auto-sandboxed)

### 🔄 Reliability
- Btrfs snapshots before updates
- Boot to previous snapshot
- Easy rollback from GRUB
- Factory reset (preserves /home)
